# Pacchetti del prodotto

Quest'area conterrà contenuti distribuiti con NewRay, separati da dati e
installazioni runtime. Fonte: NewRay.md §§9–11 e 17.

| Percorso futuro | Contenuto e vincoli |
| --- | --- |
| profiles/ | Assistant, Researcher e Coder: profile.toml e istruzioni versionate |
| skills/ | Skills dell'assistente in formato Agent Skills |
| catalogs/ | Modelli/integrazioni con origine, pin, licenza e prove |
| templates/ | Template documentali fidati e revisionati |

I binding di esempio in NewRay.md non identificano modelli già disponibili.
I manifest saranno creati insieme al validatore e al primo caso d'uso, senza
riferimenti inventati a skill o artefatti mancanti.

Importare significa rilevare, non eseguire o attivare. Installato, compatibile
e qualificato sono stati distinti. Attivazioni, grant e credenziali vivono nei
servizi runtime, non nei file distribuiti. Le skills per sviluppatori in
`agent-skills/` non vanno indicizzate nelle raccolte degli utenti.

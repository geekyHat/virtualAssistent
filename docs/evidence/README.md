# Evidenze di verifica

Registrare qui prove datate e riproducibili dei cambiamenti. Per ogni prova
indicare revisione del codice o hash dei file, eventuali modifiche locali,
comandi effettivi, ambiente, esito e limiti. Collegare la prova dal backlog
quando viene usata per chiudere un'attività.

Le prove live aggiungono modello/digest, runtime, hardware, configurazione,
corpus/versione e soglie definite prima del confronto. Usare dati sintetici
o autorizzati; omettere credenziali e contenuti privati dai report.

Una verifica di formato, un fake o una build non qualificano capacità dei
modelli, isolamento operativo o utilità per gli utenti. Non riutilizzare
percentuali del vecchio progetto o dichiarazioni vendor come risultati NewRay.

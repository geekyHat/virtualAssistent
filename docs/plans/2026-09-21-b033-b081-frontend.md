# B-03.3 + B-08.1 — Tailwind/shadcn e shell di navigazione

> **For executors:** Eseguire sequenzialmente con executing-plans; ogni task
> si chiude con la verifica indicata. I passi usano checkbox `- [ ]`.

**Goal:** Migrare la WebUI a Tailwind v4 + shadcn/ui (ADR 0005) e introdurre la
shell desktop/mobile con navigazione, `/settings` (identità + logout),
selettore lingua IT/EN, 404 e focus post-navigazione — preservando tutti i
comportamenti di sessione già verificati (11 vitest + 15 e2e).

**Approach:** Tailwind v4 CSS-first via `@tailwindcss/vite`; primitive shadcn
generate con CLI bloccata e riviste, in `src/shared/ui`; token esistenti
mappati sulle variabili shadcn (nessun redesign). La sessione resta la feature
`features/session`; i pannelli si dividono in `BootstrapPanel` (stati
signed-out/conflict/error) e `SettingsPanel` (signed-in + revoca). La shell
compone nav + area centrale; le capacità future (Documenti/Elaborati/
Collegamenti) sono voci non cliccabili che dichiarano lo stato, non pulsanti
fittizi.

**Key Resources:** `docs/adr/0005-tailwind-shadcn.md`; `docs/backlog.md`
sezioni B-03.3, TODO frontend (B-03.2-13/14/26/28/33, B-03.3+B-08.1);
`web/AGENTS.md`; baseline gate verde del 21/09 (309.2 KB JS / 2.7 KB CSS).

**Vincoli:** niente `@latest`; licenze nell'allowlist (`scripts/check-licenses.mjs`);
budget bundle JS 400 KB / CSS 64 KB; `shared` non importa feature; i18n it/en
a parità di chiavi; focus/tastiera/ARIA conservati; nessun token in
localStorage (la preferenza lingua è l'unica eccezione dichiarata: non è
sensibile).
